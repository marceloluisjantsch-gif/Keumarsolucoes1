# Keumar Soluções — Landing Page

## 🏗️ Sobre o Projeto
Landing page profissional para a **Keumar Soluções**, empresa especializada em montagem de painéis elétricos para obras industriais, galpões logísticos e projetos de retrofit.

## ✅ Funcionalidades Implementadas

- **Header/Navbar** fixo com efeito de scroll, menu mobile responsivo e links de âncora suaves
- **Hero Section** com gradiente da identidade visual, estatísticas animadas e CTAs
- **Seção Sobre** com cards visuais, badges de certificação e compromissos da empresa
- **Serviços** (6 cards) com destaque para o mais procurado: painéis industriais, galpões, retrofit, consultoria, manutenção e automação
- **Diferenciais** (6 itens) com ícones e numeração visual
- **Processo de Trabalho** em 5 etapas conectadas visualmente
- **Segmentos Atendidos** com ícones interativos
- **CTA Central** com chamada para ação
- **Formulário de Contato** com máscara de telefone, validação e simulação de envio
- **Footer** completo com links, contato e redes sociais
- **Barra de progresso** de scroll
- **Animações AOS** (Animate On Scroll) em todos os elementos
- **Design responsivo** (mobile, tablet e desktop)

## 📁 Estrutura de Arquivos

```
index.html          → Página principal
```
